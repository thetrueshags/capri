# Contributing

Use a separate profile for experiments and keep personal prompts/memories private.
Read [development](docs/development.md), run the tests, and include relevant validation
with your pull request. Describe the visible behavior you changed and how to try it.

Preserve continuous body loops, explicit loop-change transitions, monitor bounds,
media-screen protection, local-only model access and metadata-only event handling.
Do not add telemetry, new external services or automatic software/model installation
without a clear opt-in design.

For artwork, include attribution, permission details and a preview. Keep shared
anchors and authored hold times. Do not use a real person's private prompt or logs
as fixtures. Attach a redacted error excerpt rather than an entire profile.
